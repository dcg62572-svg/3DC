# 3DC — Crea tu impresora 3D

Landing page del proyecto 3DC: una impresora 3D experimental construida a partir de impresoras HP convencionales, reutilizando sus motores y mecanismos.

La página presenta el concepto como un prototipo en desarrollo e incluye el aviso **Próximamente**.

## Abrir localmente

Abre `index.html` en el navegador o ejecuta un servidor estático desde esta carpeta:

```bash
python3 -m http.server 8080
```

Visita `http://localhost:8080`.

## Estructura

- `index.html`: contenido y estructura de la página.
- `styles.css`: identidad visual responsive, ilustración de la impresora y accesibilidad.
